## Recommendation

**Stay held at 1.35.10 (option 4) and migrate to Traefik (option 1) as a separate staged PR series before hop 9.**

Why Traefik:
- It is the most mature replacement for this small, low-annotation set of Ingresses.
- It handles websockets by default.
- It's what k3s ships.
- It avoids putting L7 load on the CNI.

How to run the migration:
1. Run the new controller in parallel on a new LB IP.
2. Move Ingresses over a few at a time, internal `*.home` hosts first.
3. Move cloudflared, then the `10.20.30.200` VIP.
4. Remove ingress-nginx last.

Cilium Gateway API (option 2) is a reasonable alternative if Lee prefers Gateway API and one fewer component.

After the migration, resume B10 then B11 (hop 9 to v1.36.6+k3s1) under the existing staged gates, with a target date well before 1.35 reaches end of life.
